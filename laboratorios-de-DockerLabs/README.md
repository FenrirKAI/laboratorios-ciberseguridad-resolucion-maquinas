🟠 Laboratorios de DockerLabs

Esta carpeta contiene la documentación de los laboratorios realizados mediante **DockerLabs**.

DockerLabs permitirá practicar diferentes técnicas de ciberseguridad utilizando máquinas vulnerables en entornos controlados.

- 📡 Enumeración
- 🌐 Web Pentesting
- 💉 SQL Injection
- 💻 Command Injection
- 📂 File Inclusion

- 💥 RCE
- 📄 LFI / RFI
- 🔑 Fuerza bruta
- 🔐 Cracking
- 🐧 Linux
- ⬆️ Privilege Escalation
- ⚙️ Misconfiguraciones
- 🧩 Explotación de servicios
