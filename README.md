🛡️ Laboratorios de Ciberseguridad y Resolución de Máquinas

Repositorio personal dedicado al aprendizaje práctico de ciberseguridad, pentesting, análisis de vulnerabilidades y resolución de máquinas y laboratorios de seguridad.

Este repositorio documenta mi proceso de aprendizaje mediante diferentes plataformas y entornos de práctica, registrando las técnicas, herramientas, metodologías y conocimientos adquiridos durante la resolución de cada laboratorio.

⚠️ Aviso: Todo el contenido de este repositorio está destinado exclusivamente a fines educativos y de práctica en entornos autorizados. Las técnicas descritas deben utilizarse únicamente sobre sistemas propios, laboratorios controlados o sistemas para los cuales se tenga autorización explícita.

🎯 Objetivo del repositorio

El objetivo principal de este repositorio es construir una bitácora técnica de aprendizaje en ciberseguridad, documentando de manera organizada la resolución de diferentes laboratorios y máquinas vulnerables.

A través de estos laboratorios se busca desarrollar experiencia práctica en áreas como:

🔎 Reconocimiento y enumeración
🌐 Seguridad web
🖥️ Pentesting de sistemas
🐧 Linux
🪟 Windows
🔐 Autenticación y control de acceso
💉 Inyección SQL
🕸️ Vulnerabilidades web
📂 Enumeración de servicios
🔑 Ataques y análisis de credenciales
⬆️ Escalada de privilegios
🧩 Explotación de vulnerabilidades
🛠️ Uso de herramientas de pentesting
📡 Análisis de redes
🐳 Seguridad en contenedores
🔬 Análisis y explotación en entornos controlados
📝 Documentación técnica

La finalidad no es únicamente conseguir una flag o completar una máquina, sino comprender por qué una vulnerabilidad funciona, cómo identificarla y cómo podría mitigarse.

📚 Plataformas y laboratorios

El repositorio estará dividido en tres categorías principales:

📁 Laboratorios de THM
📁 Laboratorios HTB
📁 Laboratorios de DockerLabs

Cada plataforma tendrá su propia carpeta y documentación independiente.
